# Project Structure

Penjelasan struktur folder di `Amsyong-AI-LAB`:

- `00_Project_Management`: Jadwal, meeting notes, dan tracker.
- `01_Knowledge_Base`: Tempat penyimpanan seluruh data perusahaan untuk AI.
- `02_Prompt_Library`: Koleksi template prompt AI.
- `03_AI_Projects`: Eksperimen proyek AI spesifik.
- `04_AI_Journal`: Catatan belajar dan progres harian.
- `05_AI_Assistant` - `12_Dashboard`: Folder untuk source code atau platform per modul.
- `13_Testing`: Pengujian performa prompt dan AI.
- `14_Documentation`: Dokumentasi sistem.
- `15_Assets`: Gambar, logo, icon pendukung.
- `16_Backup`: Backup data penting.
- `99_Archive`: Dokumen dan proyek lama yang sudah tidak aktif.

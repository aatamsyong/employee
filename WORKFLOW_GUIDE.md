# Workflow Guide

Panduan alur kerja penggunaan dan pengembangan Amsyong AI:

1. **Pengumpulan Data:** Kumpulkan data mentah dari manajemen.
2. **Pembersihan Data:** Hapus duplikasi, rapikan format (ubah ke PDF/TXT jika perlu).
3. **Penyimpanan:** Simpan di `01_Knowledge_Base` sesuai kategori.
4. **Pengujian Prompt:** Buat dan uji prompt di `02_Prompt_Library`.
5. **Implementasi:** Terapkan di modul yang relevan.

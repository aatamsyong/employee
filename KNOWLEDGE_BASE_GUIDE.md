# Knowledge Base Guide

Dokumen ini menjelaskan cara menyusun dan menyimpan file ke dalam folder `01_Knowledge_Base`.

- **Company Profile:** Sejarah, visi, misi, legalitas perusahaan.
- **Proposal:** Kumpulan proposal yang pernah menang dan format standar.
- **Tender:** Dokumen persyaratan tender dan TOR.
- **Portofolio/Projects:** Data proyek masa lalu.
- **Manuals & SOP:** Prosedur operasi standar.
- **Vendor:** Data supplier dan subkon.
- **Certificates:** Sertifikat badan usaha, ISO, dsb.

**Aturan:**
- Jangan simpan file dengan nama berantakan (misal: `doc_revisi_final_banget.docx`).
- Gunakan penamaan standar: `[Kategori]_[Nama Dokumen]_[Tahun].pdf`.

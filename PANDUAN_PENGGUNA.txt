MODUL 2: PROPOSAL GENERATOR (Pembuat Proposal Word)
================================================================================

Fungsi: Membuat dokumen proposal teknis + komersial dalam format .docx.

Langkah-langkah:
1. Buka menu "Proposal Generator" di panel kiri.
2. Isi form berikut (contoh siap copy-paste):

   [Nama Klien / Calon Pengguna]
   ISI DENGAN: PT Maju Jaya Sentosa

   [Judul Proyek / Pengadaan]
   ISI DENGAN: Pengadaan 50 Unit Komputer Desktop dan Instalasi Jaringan LAN

   [Lingkup Layanan Terkait]  (centang yang sesuai, boleh lebih dari 1)
   CENTANG SEMUA:
     [x] Sistem Manajemen Dokumen
     [x] Pengadaan Komputer Desktop
     [x] Infrastruktur Jaringan LAN
     [x] Digitalisasi Arsip
     [x] Pelatihan Pengguna

   [Estimasi Durasi (Minggu)]
   ISI DENGAN: 8

   [Deskripsi Kebutuhan Khusus / Syarat KAK]
   ISI DENGAN:
   Klien membutuhkan 50 unit komputer spesifikasi i5 Gen 10, RAM 16GB,
   SSD 512GB, monitor 24 inch. Termasuk instalasi jaringan LAN untuk
   3 lantai gedung, titik 60 port, dan pelatihan kepada 20 staf IT
   selama 3 hari. Garansi minimal 3 tahun on-site.

3. Klik tombol hijau "Jalankan Agen Pembuat Proposal".
4. Tunggu 10-30 detik (ada animasi loading).
5. Hasil yang muncul:
   - Tombol "Unduh Dokumen PROPOSAL (.docx)" -> klik untuk download.
   - Pratinjau Isi Proposal -> baca di layar.
   - "Detail Eksekusi Pipeline" -> klik untuk lihat jejak eksekusi.

PANEL SAMPING: SAFETY SETTINGS (Pengaturan Keamanan)
================================================================================

Lokasi: panel kiri, bagian paling bawah, klik "Safety Settings".

4 pengaturan yang bisa diubah:

1. [Escalation threshold score] (slider 0-100)
   Arti: workflow dengan skor di bawah nilai ini akan minta persetujuan
         manual.
   Default: 50
   Saran: jangan ubah kecuali Anda paham.

2. [Max tool calls / workflow] (angka 1-200)
   Arti: batas maksimal pemanggilan tool dalam 1 workflow.
   Default: 20
   Saran: jangan ubah.

3. [Max workflow duration (seconds)] (angka 10-3600)
   Arti: batas durasi 1 workflow.
   Default: 300 (5 menit)
   Saran: naikkan ke 600 jika workflow sering timeout.

4. [Block prompts containing sensitive data] (checkbox)
   Arti: blokir prompt yang mengandung kata "password", "api_key", dll.
   Default: CENTANG (aktif)
   Saran: BIARKAN TERCENTANG untuk keamanan.

Klik "Save safety settings" setelah mengubah.

TIPS & TRIK
================================================================================

1. Jika loading lama (> 1 menit):
   - Cek koneksi internet (jika pakai API cloud).
   - Ganti provider ke "Offline Enterprise Engine".

2. Jika hasil kurang memuaskan:
   - Perbanyak detail di kolom deskripsi/poin.
   - Semakin spesifik input, semakin bagus output.

3. Jika ingin mengulang:
   - Cukup isi ulang form dan klik tombol jalankan lagi.
   - Workflow lama tetap tersimpan di Audit Log.

4. Jika ingin melihat workflow yang pernah dijalankan:
   - Buka "Audit Log Viewer" atau "Memory Viewer".

5. Jika download button tidak muncul:
   - Cek tab "Audit Trail" di bawah hasil.
   - Lihat apakah ada status "FAILED" atau "ESCALATED".
   - Jika ESCALATED, akan muncul tombol Approve/Reject.

6. Data sensitif:
   - JANGAN tulis password, API key, atau data rahasia di kolom input.
   - Sistem akan otomatis memblokir jika terdeteksi.

PERTANYAAN SERING DITANYA (FAQ)
================================================================================

T: Apakah aplikasi ini butuh internet?
J: TIDAK, jika pakai "Offline Enterprise Engine". Butuh internet hanya
   jika pakai Gemini/OpenAI/Claude.

T: Apakah data saya aman?
J: YA. Semua data disimpan lokal di komputer Anda. Tidak ada yang
   dikirim ke server luar (kecuali Anda pilih provider cloud).

T: Bisa buat proposal dalam bahasa Inggris?
J: Bisa. Tulis saja permintaan dalam bahasa Inggris di kolom deskripsi.

T: File .docx / .pptx disimpan di mana?
J: Di folder "output/" dalam direktori proyek.

T: Bagaimana cara menambah dokumen ke Knowledge Base?
J: Buka modul "Knowledge Base" -> tab "Tambah Dokumen Baru" -> upload
   file.

T: Aplikasi error / tidak bisa dibuka?
J: 1. Tutup semua jendela browser.
   2. Buka Task Manager, cari "python.exe" -> End Task.
   3. Klik ganda "run_app.bat" lagi.
   4. Jika masih error, cek folder "logs/" untuk detail.

T: Skor verifikasi selalu 100/100, apakah normal?
J: Ya, jika pakai Offline Engine. Skor akan lebih bervariasi jika pakai
   API cloud (Gemini/OpenAI/Claude).

T: Apa itu "ESCALATED"?
J: Status yang muncul jika skor verifikasi di bawah threshold (default
   50). Anda akan diminta Approve atau Reject hasil workflow.
